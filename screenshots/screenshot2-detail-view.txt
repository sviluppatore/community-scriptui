community-scriptui TUI — Screenshot 2: Script Detail View

When pressing Enter on a script from the list, the detail view appears:
- Shows the selected script's name: "backup-automation"
- Displays the description: "Automated backup scheduling script"
- Shows the source URL: "https://community-scripts.org/scripts/backup-automation"
- Provides action buttons: "Press Enter to install | Esc to go back | q to quit"
- Dark background with blue accents
- Bold yellow title for the name field
